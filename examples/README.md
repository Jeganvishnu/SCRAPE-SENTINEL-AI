# Scrape Sentinel AI — Example Structured Output Directory

This directory contains standardized JSON data artifacts demonstrating the data lifecycle of **Scrape Sentinel AI**:

- `example-success.json`: Normal structured JSON array returned by Bright Data Scraper Studio.
- `example-failure.json`: Validation engine failure event payload when required properties are missing.
- `example-healing.json`: Recorded Phase 5 healing attempt lifecycle object.
- `example-recovery.json`: Post-repair verification scrape output passing independent Phase 6 validation.
- `example-ai-diagnosis.json`: Structured AI failure diagnosis, evidence list, and Safety Gate evaluation.
- `example-schema-change.json`: Deterministic schema drift diff payload.
